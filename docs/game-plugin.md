# Игровой плагин CoreGSM (V Rising)

Небольшой плагин для игрового сервера V Rising (BepInEx). Он связывает игровой чат с панелью CoreGSM: из админки можно
отправлять сообщения игрокам, настраивать автообъявления и приветствие, а игроки видят, кто зашёл и вышел.

Плагин лежит в отдельном репозитории: [RJ-Bond/CoreGSM-Plugin](https://github.com/RJ-Bond/CoreGSM-Plugin) (там исходники,
сборка и готовый `CoreGSM.dll`).

## Что умеет

В админке пункт **«Игровой плагин»**, вкладки:

| Вкладка | Что делает |
| --- | --- |
| **Отправить** | Сообщение всем игрокам сейчас: цвета, жирный, курсив, превью «как в игре», шаблоны (свои тоже), переменные `{server}` `{online}` `{max}` `{time}` |
| **Автообъявления** | Объявление пишется один раз и уходит само: через равные промежутки, каждый день в заданное время или один раз; можно «только когда на сервере есть игроки» |
| **События** | Приветствие вошедшему игроку (лично), сообщения всем при входе и выходе игрока (цвета имени и текста настраиваются), отсчёт «через 10 / 5 / 1 минуту» перед плановым рестартом |
| **История** | Что и когда отправлено, доставлено или нет |

Плагин присылает панели название сервера, лимит и число игроков, поэтому `{server}` и `{online}` работают и для
сервера, до которого панель сама не достаёт (например, в домашней сети).

## Переменные в сообщениях

В любом сообщении (обычном, автообъявлении, приветствии) можно писать переменные, панель подставит значения для каждого сервера:

| Переменная | Что подставляется |
| --- | --- |
| `{server}` | название сервера (из панели, из запроса или от плагина) |
| `{online}`, `{max}` | сколько игроков и сколько мест |
| `{time}` | текущее время по часовому поясу панели |
| `{greeting}` | «Доброе утро / Добрый день / Добрый вечер / Доброй ночи» |
| `{restart}` | сколько осталось до планового рестарта (из плана рестартов сервера) |
| `{wipe}` | дата ближайшего вайпа (из сценариев вайпа) |
| `{discord}` | ссылка или название вашего Discord (задаётся на вкладке «События») |
| `{tip}` | случайный совет из вашего списка (там же) |
| `{name}` | ник игрока, только в приветствии и в сообщениях о входе и выходе |

Если значение сейчас неизвестно (нет плана рестартов, нет вайпа), подставляется «—».

Приветствие можно сделать разным для **нового** и **вернувшегося** игрока. Плагин запоминает, кто уже заходил, в файле
`BepInEx/config/CoreGSM.players.txt` (по одному идентификатору в строке); если удалить файл, все станут «новыми».
Готовые стили («Классика», «Готика», «Минимализм», «Праздничный») — отправная точка: нажали и поправили под себя.

## Регистрация в панели из игры

Вкладка «События» → «Регистрация в панели из игры». Когда функция включена:

1. Игрок без аккаунта при каждом входе видит подсказку: «Вы ещё не зарегистрированы в панели, введите
   `.register пароль подтверждение_пароля`».
2. Игрок вводит команду в чате. Панель создаёт аккаунт: логин берётся из игрового ника (недопустимые символы заменяются на
   `_`, занятый логин получает номер), аккаунт сразу привязывается к нику и к игровому аккаунту (идентификатор платформы).
3. Игрок получает логин и подсказку привязать Discord в профиле панели; напоминание повторяется не чаще заданного
   числа часов, пока Discord не привязан.

Соблюдаются настройки панели: если регистрация закрыта, подсказки нет; если регистрация по заявкам, создаётся заявка;
пароль проверяется так же, как на сайте; регистрация считается согласием с правилами сообщества.

Нужен плагин 0.7.0 и [VampireCommandFramework](https://thunderstore.io/c/v-rising/p/deca/VampireCommandFramework/) на
игровом сервере: он принимает команду `.register` и скрывает её от остальных игроков.

> Пароль набирается в игровом чате и проходит через игровой сервер. Команду видит только сам игрок, и плагин нигде не
> записывает пароль, но предупредите игроков не использовать пароль от других сервисов.

## Как это работает

Плагин **сам опрашивает панель** раз в несколько секунд (`GET /api/game-news/pull` с токеном) и забирает новые сообщения.
Только исходящие соединения: на игровом сервере **ничего открывать не нужно**, ни порт, ни фаервол. Панель хранит только
хеш токена. Сообщение, которое плагин не забрал за 5 минут, не доставляется (старое «рестарт через 5 минут» не должно
прийти с опозданием).

Ограничения сообщения: до 400 знаков без тегов и до 500 байт вместе с тегами (игровой чат принимает 512 байт, русская
буква занимает 2 байта). Панель предупреждает заранее.

## Что понадобится

- Игровой сервер V Rising с **BepInEx** (пакет `BepInExPack_V_Rising` с Thunderstore). Под Wine/Proton: Proton GE
  с Wine 9 и новее; для AMP достаточно включить «Activate BepInEx».
- Игровой сервер должен **видеть панель по сети** (достаточно исходящего HTTPS/HTTP до адреса панели).
- Сервер добавлен в панель: «Админка → Серверы», игра V Rising.

## Установка

1. Скопируйте `CoreGSM.dll` в `BepInEx/plugins/` игрового сервера и один раз запустите сервер: плагин создаст
   `BepInEx/config/CoreGSM.cfg`. Сервер остановите.
2. В панели: **Админка → Игровой плагин**, у сервера нажмите шестерёнку → **«Создать токен»**. Панель покажет готовый блок
   для конфига, токен виден **один раз**.
3. Вставьте блок в `BepInEx/config/CoreGSM.cfg`:

   ```ini
   [Panel]
   Url = https://адрес-вашей-панели
   Token = ...токен из панели...
   AllowSelfSigned = false
   ```

   Если панель открывается по IP с самоподписанным сертификатом, поставьте `AllowSelfSigned = true`.
4. Запустите сервер. В `BepInEx/LogOutput.log` должна появиться строка `polling … every 3 s`, а в панели сервер получит
   плашку **«Плагин на связи · vX.Y.Z»**.

Обновление плагина: замените `CoreGSM.dll`, конфиг не меняется. Если у плагина версия ниже той, под которую собрана панель,
в списке серверов будет жёлтая плашка «Плагин vX, есть vY».

## Настройки `CoreGSM.cfg`

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `Panel.Url` | пусто | адрес панели |
| `Panel.Token` | пусто | токен сервера из панели |
| `Panel.PollSeconds` | `3` | как часто спрашивать панель (2-60 с) |
| `Panel.AllowSelfSigned` | `false` | принимать самоподписанный сертификат панели |
| `Chat.MaxLength` | `400` | самое длинное сообщение, знаков |

Конфиг читается только при запуске сервера: после правки перезапустите его.

## Если что-то не работает

| Что видно | Причина и что делать |
| --- | --- |
| В логе `Panel.Url and Panel.Token are not set` | В `CoreGSM.cfg` пусто `Url` или `Token`. Заполните и перезапустите |
| `the panel does not accept the token` | Токен неверный или создан новый. В панели «Создать новый токен», вставьте в конфиг |
| `cannot reach the panel` | Сервер не достаёт до панели: проверьте адрес, сеть, при самоподписанном сертификате `AllowSelfSigned = true` |
| В панели «Плагин молчит» | Плагин не опрашивает панель: сервер остановлен, плагин старый или не заполнен конфиг. Смотрите лог |
| Сервер «висит» при старте с BepInEx | При первом запуске BepInEx генерирует библиотеки и качает базовые библиотеки Unity с `unity.bepinex.dev`. Если скачивание не идёт, положите архив `…/libraries/<версия Unity>.zip` в `BepInEx/unity-libs/`. Первому запуску нужно около 5 ГБ памяти |
| `greeting failed` / `join message failed` в логе | После обновления игры внутренние типы изменились: нужен плагин, собранный под новую версию игры |

## Безопасность

- Токен привязан к одному серверу и хранится в панели только в виде хеша; новый токен делает старый недействительным.
- Плагин не открывает порты и принимает данные только от панели, к которой сам подключается.
- Отправка и настройка доступны только администраторам.
