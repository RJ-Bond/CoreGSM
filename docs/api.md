# Публичное API (v1)

Только чтение. Для внешних сайтов, ботов и панелей мониторинга. Описание в формате OpenAPI 3: `GET /api/v1/openapi.json` (ключ не нужен).

## Ключи

Ключ создаёт администратор: «Админка → Интеграции → API-ключи». Показывается один раз. Передавайте в каждом запросе:

```
Authorization: Bearer cgsm_…
# или
X-API-Key: cgsm_…
```

У ключа есть лимит запросов в минуту (по умолчанию задаётся при создании, от 1 до 6000), необязательный список разрешённых адресов (IP или сети) и срок.
Превышение лимита: `429` и заголовок `Retry-After`.

## Ошибки

Всегда один формат:

```json
{ "error": { "code": "not_found", "message": "No such server." } }
```

## Вызовы

| Вызов | Что отдаёт |
|---|---|
| `GET /api/v1/status` | итоги: серверов, сколько онлайн, игроков |
| `GET /api/v1/servers?game=&online=` | список серверов |
| `GET /api/v1/servers/{id}` | один сервер |
| `GET /api/v1/servers/{id}/history?hours=24` | кривая игроков и пинга (до 168 часов, не больше 180 точек) |
| `GET /api/v1/servers/{id}/events?hours=168` | «упал», «вернулся», «пик», новые сверху |
| `GET /api/v1/servers/{id}/players` | число игроков сейчас; имена и время захода только пока панель открыта для гостей |
| `GET /api/v1/community?days=7` | игроков сейчас, серверов онлайн, самые активные игроки периода (имена только при открытой панели) |

Всё, что связано с именами игроков, подчиняется тому же правилу, что и сама панель: в закрытой панели имён нет. Адрес для подключения отдаётся, только если
панель открыта для гостей; адрес, по которому панель опрашивает сервер (хост и порт), не отдаётся никогда.

## Пример

```bash
curl -H "Authorization: Bearer $KEY" https://panel.example.com/api/v1/servers/1/history?hours=6
```

```json
{ "serverId": 1, "hours": 6, "points": [ { "ts": 1731321600000, "players": 21, "ping": 38, "online": true } ] }
```

## Кеш и вежливость

Ответы с заголовком `Cache-Control: private, max-age=…` (10–60 секунд): чаще опрашивать смысла нет, данные меняются по тому же таймеру, что и сама панель
(по умолчанию 30 секунд).

## Что не входит в публичное API

Управление (добавить сервер, настройки, рестарты), личные данные игроков и всё, что требует входа. Для этого есть API панели: оно не стабильно между
версиями и не предназначено для сторонних программ.
