# Локальный стенд для разработки

Панель с демо-данными в Docker, где каждое изменение кода видно сразу.

## Запуск

```
node tools/dev/dev.mjs
```

Команда сама запустит Docker Desktop (если он не запущен), соберёт образ, поднимет бэкенд и фронтенд и один раз положит демо-данные.
Первый запуск занимает несколько минут: ставятся пакеты внутри контейнера. Следующие стартуют за секунды.

- Панель: http://localhost:5173
- Вход: `admin` / `Passw0rd!long`
- Бэкенд (API): http://localhost:3000

## Как видны изменения

| Что меняете | Что происходит |
|---|---|
| `src/core-frontend/**` (компоненты, стили) | страница в браузере обновляется сама (vite, горячая замена) |
| `src/core-backend/src/**` | бэкенд перезапускается сам через секунду-две |

Файлы берутся прямо из репозитория (монтируются в контейнер), поэтому правите их в обычном редакторе.
Пакеты (`node_modules`) живут в томах Docker, так что ваши Windows-версии не мешают.

## Команды

```
node tools/dev/dev.mjs            запустить (по умолчанию)
node tools/dev/dev.mjs down       остановить, данные остаются
node tools/dev/dev.mjs reset      стереть данные и начать с чистыми демо-данными
node tools/dev/dev.mjs seed       положить демо-данные ещё раз (только в пустую панель)
node tools/dev/dev.mjs logs       смотреть журнал
node tools/dev/dev.mjs status     что запущено
```

## Что внутри демо-данных

8 серверов разных игр (один офлайн, один с очень длинным названием), история за сутки, три новости, администратор.
Адреса серверов выдуманные, поэтому опрос почти выключен (`POLL_INTERVAL_SEC=86400`): иначе серверы стали бы офлайн.
История считается от момента запуска: через сутки графики «сдвинутся», тогда выполните `reset`.

## Если что-то не так

- **Docker не отвечает.** Запустите Docker Desktop и дождитесь «Engine running».
- **Порт 5173 или 3000 занят.** Остановите то, что их использует (например, ручной `npm run dev`).
- **Изменения не видны.** Посмотрите `node tools/dev/dev.mjs logs`: ошибка компиляции видна там и в браузере.
- **Совсем с нуля:** `node tools/dev/dev.mjs reset`. Образ и тома можно удалить в Docker Desktop (`coregsm-dev`).
